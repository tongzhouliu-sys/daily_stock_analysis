# 标普 500 个股超跌反弹日频回测开发文档

本文定义一套可复现的美元多头组合回测。默认区间为 2000-01-01 至 2025-12-31，两端含当日。策略在美股常规交易时段收盘后生成信号，按下一交易日的常规开盘价模拟成交，统一计算费用、持仓、净值和参数敏感性。本文为待实现规格，文中的新增命令是实现后的验收入口。

## 1. 实现边界

- 在现有项目增加离线研究入口。完整交付包括可运行代码、依赖与运行说明、输入校验、默认参数结果、逐笔账本和 81 组参数扫描。输入数据和运行产物由外部目录提供。
- 复用扫描器的 [交易日历](../src/services/signal_scanner/domain/calendar.py)、[冻结输入及时点读取逻辑](../src/services/signal_scanner/research/inputs.py)和[产物写入工具](../src/services/signal_scanner/research/reporting.py)。新增本策略的特征计算、组合账本、出入场状态机、绩效和扫描。现有[历史建议评估引擎](../src/core/backtest_engine.py)按单条建议评估并可用盘中高低价判断触价，其出场逻辑与本策略的收盘确认契约不同。
- 回放引擎只接收按时点读取的开盘视图和收盘视图。特征计算产生信号和诊断，组合账本消费信号和公司行动，报告从已完成的账本派生。单组和扫描入口调用同一回放引擎。
- 回放只读取冻结输入，结果写入独立研究目录。回测入口独立于 Web、生产扫描任务、纸面账本和券商接口。

## 2. 数据契约与时点回放

Point-in-time（PIT）指每次决策只使用该时点已生效、已公开或已可获取的记录版本。业务生效时间与可见时间分别保存。统一以 `America/New_York` 确定交易日及常规开收盘时间，底层时间戳保存为带时区的 UTC。日历处理节假日、提前收盘和夏令时，不能按自然日加一推导次日开盘。

### 冻结输入

| 数据 | 最小字段及约束 |
| --- | --- |
| 证券主档 | `security_id`、历史 `ticker`、上市与终止日期、币种、交易所、映射的生效与可见时间。按稳定证券 ID 关联，保留退市证券、改名与代码复用记录。 |
| 标普 500 成分 | `security_id`、`effective_from`、`effective_to`、`known_at`、来源与版本。生效区间左闭右开。纳入和剔除均按实际生效时点处理，公告已发布但尚未生效时维持当日原成分。已知事件回放须能重建初始快照。 |
| 历史 GICS | `security_id`、`industry_code`、`effective_from`、`effective_to`、`known_at`、分类版本。全球行业分类标准（GICS）默认采用 6 位 Industry 层级。 |
| 个股及 SPY 日线 | `security_id`、`session_date`、常规时段原始 `open/high/low/close/volume`、`available_at`、修订版本、成交状态及来源。另保留开盘价口径和开盘可交易证据，供开盘阶段单独读取。可选同口径全日成交额 `turnover_usd`。 |
| 公司行动与退市 | 事件 ID、证券 ID、类型、`known_at`、`effective_at`、修订版本及对应拆股比例、现金金额、派息日期、换股条款或可验证的退市结算资料。 |
| 数据清单 | 文件与 SHA-256、来源及数据版本、标的与日期覆盖、日历版本、价格和成交量口径、开盘定义、各数据维度的 PIT 证据与缺失统计。 |

成分和行业数据优先使用授权历史档案。可用期初成分加带生效时点和发布时间的官方变更公告重建，逐日与可取得的历史快照交叉核对。行情候选包括 CRSP 美股历史数据，需逐项核验交易开盘口径、历史版本时间、公司行动与退市覆盖，以及 SPY 是否齐备。接入前逐段验证数据权限和实际覆盖。 [S&P DJI 指数数据能力](https://www.spglobal.com/spdji/en/documents/index-policies/index-data-capabilities-brochure.pdf) · [CRSP 美股数据](https://www.crsp.org/research/crsp-us-stock-databases-2025-layout/) · [GICS 方法](https://www.spglobal.com/spdji/zh/documents/methodologies/methodology-gics.pdf)

### 数据可见性与复权

1. 令 `t` 为信号日，`u` 为交易日历上的下一交易日。默认收盘决策截止为常规收盘后 60 分钟，可在配置中更改，但须早于 `u` 的开盘。每个历史查询选择该截止前已可见的最新版本。晚到或事后修订的数据只能影响其可见之后的决策。历史下载时间不能充当历史可见时间。
2. 行情开盘字段在开盘阶段独立读取。成交只使用该场开盘时可确定的开盘价、交易状态、已生效且可见的公司行动和分类。日终文件可以承载可验证的开盘观测，但回放开盘阶段不得访问该日高、低、收盘、全天成交量或开盘后才知道的修订。
3. 指标用截至 `t` 已可见且已生效的拆并股和现金分配因子统一调整历史 OHLC，价格锚定为 `t` 的报价单位。成交量仅按拆并股转换到 `t` 的股数单位。SPY 采用相同的价格处理。行情执行和持仓估值使用原始报价与真实股数，现金分配单独入账。
4. 从请求区间首日前读取至少 200 个交易日的预热数据，尽可能向前取得完整历史；未满足窗口的证券继续等候。纳入指数前已公开的行情可用于预热。有限回看窗口按市场日历取数，缺失 OHLC 的交易日不得用前后收盘拼接。Wilder 递推在连续有效数据段重新播种。预热期无订单和绩效记录。
5. 数据校验检查时间键唯一性、有效区间、ID 映射、价格和成交量有效性、OHLC 一致性、活跃及退市证券覆盖。校验结果按数据维度输出，保留可复现的源版本证据。

## 3. 股票池与入场信号

### 股票池和市场开关

- 信号日 `t` 取已生效且已知的标普 500 成分。使用截至 `t`（含当日）的最近 20 个市场交易日计算平均美元成交额与平均复权股数。优先使用统一口径的实际成交额，否则整次运行统一使用每日 `原始收盘价 × 原始成交量` 作为成交额代理。
- 按平均成交额降序排列，遇到并列按 `security_id` 升序，取前 `ceil(0.30 × 当日成分证券数)` 名，再筛除日均成交量低于 500,000 股的证券。排名先于成交量、GICS、趋势和信号筛选。上市不足 20 个交易日的成分不具备排名资格，仍计入成分分母。已确认全天无成交的停牌日可为流动性统计贡献零成交量和零成交额。若应有的行情缺失，导致横截面排名无法确认，当日暂停新开仓并记录受影响的成分与日期。
- 市场开关为 `SPY_Close[t] > SPY_SMA200[t]`，SMA 为简单移动平均，窗口含 `t`。等于均线、SPY 不可用或历史不足时关闭新仓。已有持仓按出场规则管理。

### 入场条件

| 条件 | 计算及比较口径 |
| --- | --- |
| A 趋势 | `Close[t] > SMA200[t]`，窗口含 `t`。 |
| B 暴跌 | 满足任一项。`RSI2[t] < 10`、`Close[t] / Close[t-3] - 1 <= -0.08`、`Close[t] / Close[t-1] - 1 <= -0.05`。`t-3` 是市场日历上往前三个交易日，需要四个收盘价。 |
| C 放量 | 满足任一项。`Volume[t] >= 2.0 × mean(Volume[t-20:t-1])`、`Z > 2`。基准为 `t` 前 20 个市场交易日，区间两端均含且排除 `t`。`Z = (Volume[t] - mean) / std`，标准差采用总体口径 `ddof=0`。均值非正或窗口不完整时 C 无效。标准差为零时仅判断倍数条件。 |
| D 止跌 K 线 | `range = High - Low > 0`。同时满足 `min(Open, Close) - Low >= 0.60 × range`、`min(Open, Close) - Low >= 0.50 × ATR14[t]` 和 `abs(Close - Open) <= 0.30 × range`。 |

四项必须同时成立。相对强弱指数 `RSI(2)` 使用两期 Wilder 平滑。以连续两次收盘差分的平均涨幅和平均跌幅绝对值播种，后续按 `(上期均值 + 当期值) / 2` 更新。两者皆零时 RSI 为 50，仅平均跌幅为零时 RSI 为 100，仅平均涨幅为零时 RSI 为 0。RSI 必须可计算，以便对所有候选使用同一排序键。

平均真实波幅 `ATR(14)` 使用 Wilder 法。`TR[t] = max(High[t] - Low[t], abs(High[t] - Close[t-1]), abs(Low[t] - Close[t-1]))`。以首 14 个具备前收盘的连续 TR 算术平均播种，后续用 `(13 × ATR[t-1] + TR[t]) / 14`。信号日 ATR 须有限且大于零。

## 4. 订单、仓位与账本

### 每日事件顺序

1. **开盘前**读取已生效且可见的公司行动，处理持仓股数、应收和证券映射。载入上一收盘已确认的卖单和当日有效的买入候选。
2. **开盘**先成交可执行的卖单，释放相应资金与名额。买入按信号日 `RSI(2)` 升序执行，同值以 `security_id` 升序，按当前现金、权益和名额逐笔定量。某候选失败时继续考虑排序中的下一只。信号日已有该证券持仓时不生成新买单，持仓期间不加仓。
3. **收盘后**使用收盘可见数据记录日终净值和估值质量，检查已有持仓出场，再生成下一开盘的买入候选。末日收盘产生的订单以待执行状态留档。

### 开仓计算

设 `O` 为 `u` 的真实常规时段开盘价，`A` 为冻结的信号日 `ATR(14)`，必要时按 `t` 至 `u` 之间生效的拆并股比例换算为 `u` 的每股报价单位。`E` 为该笔开仓前的总权益，包括现金、已确认应收与现有持仓市值。已有持仓优先按可见的有效开盘价估值，缺失则用最近已知有效标记，记录陈旧天数。每笔成交后更新权益和现金。

```text
entry_reference = O
stop_price = O - atr_stop_multiple * A
price_risk_per_share = O - stop_price
buy_fill = O * (1 + slippage_rate)
sell_fill = O * (1 - slippage_rate)
commission = shares * fill_price * commission_rate

risk_shares = floor(E * risk_fraction / price_risk_per_share)
cap_shares = floor(E * position_cap / O)
cash_shares = floor(available_cash / (buy_fill * (1 + commission_rate)))
shares = min(risk_shares, cap_shares, cash_shares)
```

- 按原规则，当 `O <= stop_price` 时取消买入。因为止损以同一个 `O` 减去正的 ATR 距离得到，有效输入下该比较恒为假。若需要独立的向下跳空过滤，须另行指定一个在开盘前已确定的参考价。首版沿用原公式。
- 每笔名义止损风险上限为开仓前权益的 1%，单只开仓市值上限为 15%。规模按未滑点开盘价与止损差计算，买卖成本进入账本。次日开盘跳空与交易成本可能使实际亏损超过 1%。开仓后市值随价格和权益自然变动，15% 约束在新开仓时检查。
- 最大同时持仓 10 只，单个 GICS Industry 最多 2 只。开盘分配使用当时有效且可见的分类，重新计入已有仓位。候选缺少分类时跳过。已有仓位分类不明时，开仓校验将未知仓位全部计入候选行业作为上界。若行业重分类使已有仓位超过上限，记录超限并停止在该行业加新仓，已有仓位继续按退出规则处理。
- 默认仅用可用现金，禁止负现金和杠杆。模拟卖出资金同一开盘可用于新买入，不模拟券商结算冻结、利息和税项。股数不足一股时取消。开盘价决定同一开盘的模拟数量与成交，属于统一开盘成交假设，报告应披露开盘可得性、成交规模和该假设的限制。
- 默认单边佣金 `0.00005`（0.005%），单边滑点 `0.0005`（0.05%）。以成交金额计佣，无最低费用。内部计算保留足够精度，取整发生在股数约束，账本汇总后再按展示精度舍入。

### 出场规则

| 优先级 | 原因码 | 收盘触发条件 |
| --- | --- | --- |
| 1 | `HARD_STOP` | 有效原始收盘价 `<= stop_price`。止损距离基于信号日 ATR 冻结，持有期仅随拆并股转换报价单位。 |
| 2 | `TIME_STOP` | 入场日算第 1 个市场交易日，第 10 个交易日收盘触发。停牌日仍随市场日历计数。 |
| 3 | `SMA20_EXIT` | 当日复权收盘价 `>= SMA20`。SMA 使用包括当日在内的最近 20 个交易日，入场日收盘即开始检查。 |

每日依表顺序保留首个满足的原因，排入下一交易日开盘卖单。订单一经生成，原因和触发日保持冻结。硬止损比较原始收盘价与同股数单位的止损价。盘中最高价或最低价触及目标不触发订单，开盘触及止损也不直接触发新卖单。市场开关关闭、流动性落出股票池或剔除指数均不改变已有持仓的出场规则。

### 停牌、缺失和公司行动

| 情形 | 行为及记录 |
| --- | --- |
| 买入日无有效常规开盘，或开盘时不可交易 | 取消当笔买单并记录原因。只在原定开盘有效，下一交易日须由新信号触发。 |
| 卖出日无有效常规开盘，或开盘时不可交易 | 原因不变，保留持仓和占用名额，顺延至首个可验证的常规开盘。记录计划与实际卖出日期及延迟交易日。 |
| 持仓缺少有效收盘 | 以最近已知有效价格估值并标记陈旧。硬止损及 SMA20 当日无从判定，时间止损按日历在收盘时点照常检查。缺失日和陈旧市值单列，严禁用未来行情补足。 |
| 拆并股、现金分配 | 拆并股同步调整股数、单位成本及止损。零碎股按已知处置条款计入账本。现金分配按除息时符合领取条件的持股登记为应收，到账时转为可用现金，交易损益纳入已确认分配。晚到的事件按其可见时间入账，按历史持股记录确定权益归属。常规现金分红不重设名义硬止损。 |
| 并购、永久退市或破产 | 按已证实的现金/证券对价或退市结算数据，在相应可见且生效时点入账，保存为 `CORPORATE_SETTLEMENT` 处置，并保留原待执行卖单原因。换股对价按可验证价值记入权益，转入证券头寸后在可交易开盘处置，记录处置原因。未知对价继续列为未解决，披露估值假设并将受影响的绩效标为暂定。禁止静默删除仓位或编造开盘成交。 |
| 到达回测期末 | 以最后有效收盘标记未平仓，列出未实现盈亏、陈旧估值及未成交订单。期末后成交和最终才获知的退市对价不计入主区间。 |

## 5. 回测参数和运行入口

| 配置键 | 默认 | 说明 |
| --- | --- | --- |
| `start_date`, `end_date` | `2000-01-01`, `2025-12-31` | 含边界自然日，实际回放按交易日历。 |
| `initial_equity` | `100000` | 初始权益与现金，美元。 |
| `decision_delay_minutes` | `60` | 以当日常规收盘为锚点的决策延迟。 |
| `commission_rate`, `slippage_rate` | `0.00005`, `0.0005` | 单边比例。 |
| `liquidity_fraction`, `min_avg_volume` | `0.30`, `500000` | 成交额排名比例和最低日均股数。 |
| `risk_fraction`, `position_cap` | `0.01`, `0.15` | 单笔名义风险与单只开仓市值上限。 |
| `max_positions`, `max_per_industry` | `10`, `2` | 同时持仓和 GICS 行业上限。 |
| `atr_stop_multiple`, `max_holding_sessions` | `2.0`, `10` | 硬止损距离与时间止损。 |
| `rsi_threshold`, `volume_multiple` | `10`, `2.0` | 只调整各自 OR 分支，跌幅阈值和 Z 阈值固定。 |

实现后的 CLI 提供 `validate`、`run` 和 `sweep`。`--manifest` 指定冻结数据清单，`--config` 可选，指定含上述参数覆盖值的 JSON 文件。`validate` 返回覆盖和可用模式。`run` 执行基准回放并生成报告。`sweep` 在同一冻结输入上执行敏感性扫描。以下示例在仓库根目录运行，输入目录由数据准备流程提供。

```bash
python -m src.services.signal_scanner.research.us_equity_rebound validate --manifest "$INPUT_DIR/manifest.json"
python -m src.services.signal_scanner.research.us_equity_rebound run --manifest "$INPUT_DIR/manifest.json" --output "$OUTPUT_DIR/baseline"
python -m src.services.signal_scanner.research.us_equity_rebound sweep --manifest "$INPUT_DIR/manifest.json" --output "$OUTPUT_DIR/sensitivity"
```

完整扫描为 81 组独立组合回测。止损 ATR 倍数 `{1.5, 2.0, 2.5}`、时间止损 `{7, 10, 15}`、RSI(2) 阈值 `{5, 10, 15}`、成交量倍数 `{1.5, 2.0, 2.5}`。复用各组一致的时点数据和底层特征，每组独立模拟资金路径和竞争排序。报告同时给出其他参数固定为默认值时的单因素切片。默认组合在扫描中的结果应与 `run` 一致。

运行清单保存实际配置、输入哈希、实现与依赖版本、日历、运行模式和稳定业务结果哈希。相同输入与配置复跑得到同一业务结果。先写入临时目录，完整校验后发布，避免失败重跑留下混合产物。

## 6. 降级与结果解释

| 不可获得的数据 | 可继续执行的路径 |
| --- | --- |
| 全区间 PIT 标普 500 成分 | 优先重建带时间证据的历史名单或缩短至可验证覆盖段，并披露实际日期。只有事后历史名单时标记 `REVISED_HISTORY`。只有当前名单时可另跑 `CURRENT_UNIVERSE`，报告明确存在幸存者偏差。 |
| 历史 GICS Industry | 优先缩短至可验证覆盖段，零星缺失按开仓规则跳过。可用历史 Sector 或历史 SIC 分组做单独的代理实验，或取消行业上限做单独诊断，报告注明约束变化。 |
| SPY 或复权证据 | 优先从可验证的替代来源补齐 SPY，或缩短区间。无法补齐 SPY 时可用明确标注的指数价格代理做探索。缺乏可验证的公司行动或开盘证据时，排除对应输入、缩短区间或使用明确标注的修订后序列。需要模拟成交的模式仍须有可解释的常规开盘价格。 |
| 没有可用的真实历史数据 | 用明确标注为 `SYNTHETIC` 的数据运行端到端测试，交付工程验收报告，保留真实数据回放的缺口。 |

每份报告分别披露成分名单、历史分类、行情修订、开盘、公司行动及退市覆盖证据。只有相关维度可验证且覆盖符合运行区间时，才将结果标为 `POINT_IN_TIME`，并声明相应成分回放和退市覆盖情况。降级运行用 `--config` 显式选择替代输入或约束，保留自身配置、覆盖分母、排除原因与结果，单列受影响的指标和结论。SPY 缺口和横截面不可计算的日期继续维护已有持仓和账本。

## 7. 交付产物与绩效公式

| 产物 | 内容 |
| --- | --- |
| `report.md`、`summary.json` | 回测假设、指标、年度与退出归因、回撤起止、数据质量与降级说明。 |
| `trades.csv` | 证券 ID、当时 ticker、GICS、信号及执行日期、入场信号指标、ATR、止损、股数、开盘与模拟成交价、两侧费用、退出信号日与优先级、分配和结算、净盈亏、净收益率及持仓交易日。 |
| `orders.csv`、`open_positions.csv` | 所有候选的排序、分配和拒绝原因，待成交或延期订单、未平仓标记与未解决公司行动。 |
| `equity.csv`、`annual_returns.csv` | 逐日现金、应收、持仓市值、净值、收益率、回撤、陈旧标记及年度收益。 |
| `exit_breakdown.csv`、`sensitivity.csv` | 按退出原因的交易数量和净盈亏，参数扫描中每组的参数、主要指标、交易数及有效性。 |
| `run_manifest.json`、`data_quality.json` | 可复现清单、逐维度 PIT 判定、停牌、缺失、退市处置、估值和跳过统计。 |

- 总收益为 `期末净值 / 初始净值 - 1`。复合年增长率（CAGR）为该净值比按实际经过的自然日年化，按 `365.2425 / 经过天数` 取幂再减 1。初始净值以首个计入交易日开盘前为锚，期末净值取区间末个交易日收盘。
- 日收益为相邻估值间的净值变动，含零仓位日。夏普比率为 `sqrt(252) × mean(日超额收益) / stdev(日超额收益)`，采用样本标准差，默认无风险利率为零。年度收益按每年首日前最后一个估值与当年最后一个估值计算，首年用初始净值，部分年度标注覆盖区间。
- 最大回撤以日终净值相对历史峰值的最低百分比表示，初始净值参与峰值计算。报告给出峰值日、谷值日、恢复日至前峰的时间，未恢复时标记截至期末仍未恢复。多个相同谷值取首次，该谷值前同峰值取最近一次。
- 胜率为净盈亏大于零的已结束交易数除以全部已结束交易数，零盈亏计入分母。报告分别给出平均盈利和平均亏损的美元值与单笔净收益率均值。盈亏比用平均美元盈利除以平均美元亏损绝对值。Profit Factor 用所有正净盈亏之和除以所有负净盈亏之和的绝对值。收益率分母为含佣买入成本，无有效分母的指标用 `null` 并写明原因。
- 交易次数采用完整闭合的往返笔数，并单列开仓数和期末未平仓数。持仓天数按市场交易日计算，包含入场日、排除开盘平仓日。公司行动结算按持仓实际终止时点计算。
- 出场分解固定展示 `HARD_STOP`、`TIME_STOP`、`SMA20_EXIT` 的笔数及净盈亏，非策略结算单列。已实现归因之和与交易账本核对，再与未实现盈亏及独立公司行动账项对账至期末权益变化。

## 8. 验收顺序

1. **数据验收**。抽查区间起止、数次指数换股、历史行业变更、退市和代码复用。验证提前公告、尚未生效的成员不能入池，旧版本数据在修订可见前持续生效。检查数据清单、哈希和实际回测覆盖。
2. **信号验收**。用可手算样本核对 Wilder 初值、三日跌幅、RSI 和 Z 严格比较、放量基准排除当日、K 线边界、零区间、SPY 等于 SMA200 和流动性分位并列。修改未来 bar、开盘后字段、未来公司行动及事后修订，断言此前信号、下单和成交不变。
3. **成交验收**。验证次日开盘、卖先买后、同分排序、资金和名额抢占、行业重分类、滑点佣金与整股取整。验证停牌买单取消和卖单顺延、止损跳空损失、拆股换算、除息应收、退市结算、同日出场优先级，以及入场日算第 1 日时的第 10 日触发与第 11 日开盘成交。
4. **账本验收**。独立重算现金、股数、日终权益、年度收益、最大回撤、交易归因与期末未平仓。覆盖零交易、全赢、全亏和全程现金场景。逐日确认普通订单的 `信号时间 < 成交时间`，且成功入场符合当时的股数、现金和持仓限额。
5. **全流程验收**。运行离线单测和 `./scripts/ci_gate.sh`，按实际覆盖运行 `validate`、`run` 与 `sweep`，验证 81 组齐全、默认组合一致、重复运行的业务结果哈希一致。交付代码、运行命令、可核对产物及未验证数据维度。真实数据不足时交付可取得数据下的回放结果和降级说明。
