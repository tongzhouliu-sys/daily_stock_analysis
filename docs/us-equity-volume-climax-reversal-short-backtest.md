# 成交量高潮反转做空策略｜回测需求与开发任务

策略英文名为 Volume Climax Reversal Short。交付一套可用 Python/pandas 或等价实现运行的美股日线组合回测。先交付可运行代码、依赖和运行说明，再用同一回测入口生成默认结果、交易明细、基准对比与参数敏感性。实现作为现有项目的离线研究能力，输入为冻结的历史数据，结果写入独立的研究目录。

## 一、回测需求

### 1. 范围与默认参数

| 项目 | 默认口径 |
| --- | --- |
| 回测期 | 2010-01-01 至 2025-12-31，两端含当日，以美东交易日历取实际开市日。 |
| 股票池 | 当日主上市交易所为 NYSE 或 NASDAQ 的美股普通股。按历史证券类型筛选，排除 ETF、ETN、封闭式基金，保留当时符合条件的后来退市股票。 |
| 价格与流动性 | 信号日原始收盘价严格大于 5 美元，过去 20 个交易日平均美元成交额（ADV20）严格大于 2,500 万美元。 |
| 融券 | 优先已确认的普通抵押品（General Collateral，GC）券源。开仓时已知实际年化借券费率大于 20% 或不可借则放弃。费率缺失时默认 10%。 |
| 组合 | 同一证券最多一笔空头，组合最多 10 笔。新开仓后空头总名义敞口至多为权益的 100%，单笔初始价格风险至多为权益的 1%。 |
| 执行与费用 | 信号日收盘后确认，下一交易日常规时段开盘做空。单边滑点 10 bps（1 bp 为 0.01%），佣金默认 0 美元，可设为每次成交 1 美元。 |
| 可选过滤 | K 线冲高回落过滤 `require_rejection` 与财报过滤默认关闭。财报过滤启用时只使用决策当时可见的财报日历。 |
| 绩效基准 | 同起止日期的 SPY 含分红再投资总回报，以相同初始权益归一化。 |

初始权益以美元配置，建议默认 100,000 美元并在结果中显式记录，便于复现整股取整后的差异。默认以最后一个回测日收盘估值结束。期末未平仓的持仓及其已实现、未实现损益单列，末日信号仅留档。

### 2. 数据与时点契约

回测按美东交易日推进，处理节假日、提前收盘和夏令时。每条输入保留生效时间、历史可见时间、来源与版本。信号在配置的收盘后截止时点计算，建议默认常规收盘后 60 分钟。开盘撮合独立读取当时可见的开盘价和可交易状态，开盘阶段的数据接口仅提供该阶段已知字段。 [NYSE 交易时段与日历](https://www.nyse.com/trade/hours-calendars)

| 输入 | 最小数据与处理要求 |
| --- | --- |
| 历史证券主档 | 稳定证券 ID、历史代码及其有效期、上市交易所、证券类型、上市及退市事件。以证券 ID 串接历史，处理改名和代码复用。 |
| 个股与 SPY 日线 | 常规时段原始开高低收、成交量（OHLCV），开盘及收盘的时点证据、停牌状态；如有同口径实际美元成交额则优先使用，否则本次运行统一用原始收盘价乘原始成交量代理。 |
| 公司行动 | 除息日与每股现金分红、拆并股比例、并购及退市结算信息，均保留事件 ID、有效期和可见版本。 |
| 融券 | 证券 ID、费率、可借状态、可借数量（如有）、GC 分类、有效期及可见时间。状态缺失与费率缺失分别统计。 |
| 财报与市值 | 财报日期、当时可见的排期版本及其发布时间。市值用当时已知的证券市值，或用原始收盘价乘当时已知且与报价单位一致的在外股数，缺失单列。 |
| 数据清单 | 来源、版本、文件校验值、行情口径、实际覆盖日期、预热范围、缺失及修订统计。 |

- 指标用截至信号日已知且生效的拆并股和现金分红因子复权，价格锚定到信号日报价单位。成交量只做拆并股转换。价格过滤、ADV20、撮合和账本使用原始行情及实际股数，分红独立记账。信号到开仓间如有拆并股，先转换信号价格和 ATR，再比较跳空和计算订单。持仓期间同步转换股数、单位成本、止损及止盈价，保证拆并股前后经济敞口一致。
- 回测开始前至少读取 252 个交易日作预热。回看窗口按市场交易日取数，两端含当日；指标窗口不完整时跳过该信号。缺失行情单独诊断，确认停牌可在流动性统计中记零成交额，缺失记录不得填成零或补出虚假 OHLC。
- 已知无法在下一场常规开盘交易时，候选当场失效。持仓遇到停牌或缺行情时，以最近可核验标记暂估并披露陈旧天数，恢复交易后按有效开盘及后续退出规则处理。退市按可核验的结算事件入账；结算缺失标为未决并披露影响，正式绩效标为不完整。
- 财报过滤启用时，剔除信号日前一交易日、当日或后一交易日存在当时已知财报日期的候选。缺少可核验的历史日历时跳过对应过滤并统计。借券可得性未知时，允许在估算情景中按假设模拟，并与有券源证据的结果分别标注。
- 正式结果以可核验的历史股票池和输入时点为前提。仅覆盖现存证券时报告幸存者覆盖缺口。只有期末复权价或事后才可见的修订记录时，相应行情不进入决策，报告受影响的标的、日期和字段。若只能用合格子样本运行，明确标注范围及其与完整股票池的差异。CRSP 可作为证券主档、日线与公司行动的候选来源。开盘字段、历史可见性、实际权限及覆盖须用样本核验。融券另核验可借数量和历史费率能否覆盖开仓及持仓时点。 [CRSP 美股历史数据](https://www.crsp.org/research/crsp-us-stock-databases-2025-layout/) · [IBKR 借券费率历史](https://www.ibkrguides.com/traderworkstation/slb-rates.htm) · [IBKR 可借状态](https://www.ibkrguides.com/orgportal/shortstock.htm)

### 3. 信号计算

设 `T` 为信号日，`C/O/H/Lo/V` 分别为收盘、开盘、最高、最低和成交量。以下指标使用同一信号日复权口径。通过股票池、价格和流动性过滤后，须同时满足以下条件。

| 条件 | 默认公式 |
| --- | --- |
| 加速上涨 | `C[T] > SMA20(C)[T] > SMA50(C)[T]`，`C[T]/C[T−20] − 1 ≥ 30%`，`C[T]/C[T−5] − 1 ≥ 10%`，且 `C[T] = max(C[T−19…T])`。 |
| 波动放大 | `ATR14[T] / ATR14[T−20] ≥ 1.5`。平均真实波幅（ATR）用 Wilder 平滑，以首 14 个有前收盘的连续真实波幅均值播种。两个 ATR 均须有效且大于零。 |
| 高位 | `C[T] ≥ 0.95 × max(C[T−252…T])`，按显式区间取 253 个收盘价。 |
| 底部启动量 | `L` 为 `[T−120,T−5]` 内最低收盘价对应日，并列取最早一日。窗口 `W=[L−5,min(L+10,T−1)]`，`V_base_max=max(V[W])`。要求 `V[T] ≥ 1.5 × V_base_max`。 |
| 天量 | `V[T] ≥ 2.5 × SMA20(V)[T]` 且 `V[T] = max(V[T−120…T])`。均量包含 `T`，天量极值窗口为 121 个交易日，极值并列允许通过。 |
| 可选冲高回落 | 开启后须满足 `(H[T]−C[T])/(H[T]−Lo[T]) ≥ 0.33` 或 `C[T] < O[T]`。日内振幅为零时，仅判断后一条件。 |

SMA 为简单移动平均，20 日和 50 日均线分别取截至 `T` 的 20 和 50 个交易日。真实波幅为 `max(H−Lo, abs(H−前收盘), abs(Lo−前收盘))`。记录每项中间值、未通过原因、`L` 及窗口边界，以便复核。

### 4. 入场、仓位与组合约束

- 下一市场交易日开盘为唯一入场时点。设原始开盘价为 `O_next`、滑点率为 `s`、信号日 ATR 为 `A`。若 `O_next > H[T] × 1.02` 或 `O_next < C[T] × 0.95` 则放弃；等于边界允许。入场卖出价 `S = O_next × (1−s)`。
- 初始止损 `SL = max(S+1.5A, H[T]×1.005, S+0.8A)`。每股初始风险 `R=SL−S`；`R/S > 12%` 时放弃，等于 12% 允许。ATR 止损敏感性只替换公式里的 `1.5`。
- 每笔开仓前按当时可见价格计算权益 `E`。风险股数 `floor(E×1%/R)` 再受可借数量和剩余敞口约束；已知可借量为零或最终股数为零则放弃。敞口按开盘市价乘未回补股数计算，核验新成交后计入滑点和佣金的权益。权益为非正时暂停新开仓。
- 同一开盘候选先按已确认 GC 优先，再按信号日 ADV20 降序、证券 ID 升序，逐笔更新权益、敞口及名额。已有空头时同标的候选失效。开盘和收盘均记录存量因价格变化出现的超限，开盘仍超限时冻结新仓，存量按策略退出规则管理。
- 开仓检查用该时点有效且可见的实际借券费率。实际费率大于 20% 或明确不可借时拒绝开仓。费率缺失可启用流动性分档，`ADV20 > $100M` 取 5%，其余合格标的取 10%；默认用固定 10%。

### 5. 止盈、止损与日线撮合

1. `TP1_candidate = C[T]`，条件为 `S ≥ C[T]×1.005`；否则取 `S−A`。最终 `TP1=min(TP1_candidate,S−0.5A)`。
2. `TP2_raw=max(C[L],H[T]−0.5×(H[T]−Lo[L]))`，`TP2=min(TP1−0.5A,TP2_raw)`。若计算后 `TP2 ≥ TP1`，回退为 `TP1−A`。TP1 回补初始股数的 50%，整股向下取整；TP2 回补剩余股数。TP1 只触发一次。仅有一股时记录 TP1 触发，整股留待后续退出。
3. 止损止盈自入场日开始。某日开盘 `O ≥ SL` 时按开盘价止损；否则 `High ≥ SL` 时按止损价回补。某日止损与任一止盈同时触发时，统一按止损回补当日全部剩余股数。若当天无止损，`Low ≤ TP` 即触发对应止盈；若开盘已低于或等于该 TP，则以开盘价作为该笔回补基准。同日触及两个 TP 时依次记两笔回补。所有基准价再应用买入滑点。
4. 同日止损优先规则也覆盖低开穿越 TP 后日内触及 SL 的情况。低开止盈在整根日线可用后按上述规则归属；同一开盘的新仓只可使用当时已确定的退出释放出的名额或敞口，例如开盘跳空止损。
5. 盘中最低价首次达到 `S−R` 且日终仍持仓时，下一交易日开盘前将 SL 移到 `S`。再下一交易日起，使用前一日有效最高价更新为 `min(原SL, 前一日最高价×1.005)`。当日的新止损以开盘前冻结值为准，缺少前一日有效最高价则保留原止损。
6. 入场日为持仓第 1 个市场交易日。第 20 日先处理当日止损和止盈，余仓按该日收盘价回补。若当日无法收盘成交，记录待退出并在下一可交易开盘处理；此时如已跳空触发止损，按开盘止损归因。

### 6. 成本、账本与结果

- 买入回补成交价 `P=撮合基准价×(1+s)`。按每笔回补的数量计算毛盈亏 `(S−P)×股数`，再扣借券费、空头支付分红及佣金。账本逐日以现金减空头市值计算权益，借券费和分红按确认时点计入，滑点已经反映在成交价中。
- 借券费按自然日累计，使用 `每日未回补股数×对应每股入场价×当日有效年化费率/365`。按入场日含、对应回补日不含计费，周末计入，日内开平为零天；部分回补后按剩余股数计费。使用当时可见且有效的每日费率，缺失按配置回退；持仓期间出现高于 20% 的实际费率仍据实入账。
- 按除息日前一交易日收盘持有的实际空头股数乘每股分红扣账。除息日开盘才建仓不扣该笔分红；跨除息日持仓即使在除息日开盘回补仍计入。已知存在分红但金额缺失时将该仓成本标为待核验。 [IBKR 空头股息补偿说明](https://www.ibkrguides.com/traderworkstation/about-pre-borrows.htm)
- 交易指标按完整开平仓轮次统计，并另报开仓次数与期末未结笔数。胜率为净盈利轮次占全部已结轮次，平均亏损以绝对额展示，盈亏比为平均盈利除以平均亏损，期望收益为平均净盈亏，同时提供美元和初始风险倍数口径。最大连续亏损按全平时间排序，同阶段同日以稳定证券 ID 打破并列。持仓天数报告市场交易日均值，另保留借券自然日。
- 组合指标基于扣费后的每日权益，输出年化收益、最大回撤、Sharpe、Sortino、Calmar。年化收益以回测首日开盘前的初始权益和末日收盘权益计算复合年增长率，按实际经过的日历天数以 365.25 天折年。回撤用逐日权益相对历史峰值计算，初始权益计入峰值。Sharpe 和 Sortino 取零无风险利率及零目标收益，以 252 日年化，分别用日收益样本标准差和全样本下行均方根作分母。Calmar 为年化收益除以最大回撤绝对值。样本不足、权益非正导致无法计算或分母为零时返回空值及原因。
- 退出报告同时给出事件触发率和全平原因占比。事件触发率分母为开仓轮次，TP1、TP2 等可在同一轮次同时出现；全平原因分母为已结轮次，区分初始止损、保本止损、跟踪止损、TP2、时间退出及退市等结算事件。
- 分组用信号日可见的市值、ADV20、`ATR14/C` 与开仓借券成本及来源，按配置固定档位，未知值单列。建议默认市值低于 20 亿、20 亿至不足 100 亿、100 亿美元以上（含）；ADV20 分界为 1 亿美元，等于分界归较低档；波动率按低于 3%、3% 至不足 6%、6% 以上（含）；借券费率按不超过 5%、大于 5% 至 10%、大于 10% 至 20%。每档输出样本数、胜率、期望、净盈亏及成本，分档归因使用同一组合的成交记录。
- 将策略与 SPY 总回报放在同一日期轴对比净值、年化收益和最大回撤。SPY 基准从回测首个交易日的常规开盘起算，含分红再投资。基准覆盖缺失时单列日期与原因，绩效比较仅使用两条净值都有有效数据的共同区间，并披露其起止日期。

### 7. 参数敏感性

固定数据快照、日期、基准、资金和撮合规则。默认组与每个参数的非默认档分别运行，单因素扫描共 11 次，每次从相同初始状态重新构建组合。报告每档的交易数、净盈亏、期望、年化收益、最大回撤、Sharpe 和总成本，并显示相对默认组的差值。

| 参数 | 档位 |
| --- | --- |
| 20 日加速阈值 | 20% / 30% / 40% |
| 相对底部启动量倍数 | 1.2 / 1.5 / 2.0 |
| 初始 ATR 止损倍数 | 1.0 / 1.5 / 2.0 |
| 单边滑点 | 5 / 10 / 20 bps |
| 缺失时的年化借券费率 | 5% / 10% / 20%，有效的实际费率保持原值。 |

敏感性用于展示全样本内参数变化的影响，保留默认策略的独立结果。注明各档实际费率覆盖比例，便于判断借券成本情景影响了哪些交易。

## 二、开发任务与验收

1. **冻结数据与覆盖审计。** 接入历史主档、原始日线、公司行动、SPY，验证借券、财报和市值可选输入。实现开盘与收盘阶段的数据读取约束、预热校验和覆盖报告。验收样例包含后来退市、代码复用、停牌、晚发布修订、提前收盘和拆股；抽样证明相同证券跨代码连续，后发布版本仅从可见时点开始生效。
2. **实现信号与诊断。** 实现复权、交易日窗口、Wilder ATR、底部定位和增强过滤。输出信号快照及拒绝原因。用人工构造的 OHLCV 核对 20/121/253 日窗口、阈值等号、并列底部与 `W` 截断。追加或修改在 `T` 决策截止之后才可见的行情、财报版本、拆股和借券记录，`T` 的已确认信号保持一致。
3. **实现组合回放与空头账本。** 实现下一开盘撮合、跳空过滤、排序、整股仓位、部分退出、1R 状态、跟踪止损、分红及借券费。验收覆盖两类跳空、同日止损与双 TP、低开触 TP 后冲 SL、下一日才生效的保本止损、第 20 日平仓、单股仓位、容量竞争、敞口和可借量约束，以及周末、分红、拆股、退市和期末未平仓。变动入场日的高低收与全天成交量，开盘成交和仓位应保持一致。
4. **实现绩效、归因和参数扫描。** 从同一账本派生指标、退出与分组归因、SPY 对比和 11 组敏感性。用手算账本核对部分回补、费用、未实现盈亏与组合净值；覆盖零交易、全赢、全亏、分母为零和基准缺失。核对开仓、回补股数、净盈亏、费用与日终权益可逐项对账。
5. **交付入口与真实样本结果。** 在现有仓库提供离线 CLI、依赖、参数示例、最小演示数据与运行说明。优先评估复用现有[交易日历](../src/services/signal_scanner/domain/calendar.py)、[研究输入](../src/services/signal_scanner/research/inputs.py)和[产物写入](../src/services/signal_scanner/research/reporting.py)。当前[建议评估引擎](../src/core/backtest_engine.py)面向历史多头建议，空头组合撮合需要单独实现并验证。先用演示数据跑通，再用具备权限和覆盖的数据生成完整回测。验收要求同一快照、配置与代码版本可复现业务结果，真实数据未覆盖的区间或费用维度在报告内明确列出。

### 交付产物
