# stock-answer-editor

## 概述

回答精编 skill，在分析完成后对原始回答进行结构化重排，输出结论先行、证据支撑、风险可见的精读格式。

## 触发条件

- 由 `AgentChatExecutor` 或 `AgentOrchestrator` 在最终风险收敛后自动调用
- 仅在 `analysis_brief` 已确认（`intake_status == 'confirmed'`）时启用
- 用户不可手动调用

## 输入

- `original_response`: 原始分析回答（Markdown 格式）
- `analysis_brief`: 用户确认的分析简报
- `source_refs`: 引用的数据源列表

## 输出

结构化 Markdown，包含以下层级：

### 1. 结论摘要（Conclusion Summary）

- 1-3 句话概括核心结论
- 明确标的、方向、时间框架
- 包含关键数据点（价格、涨跌幅、目标位）

### 2. 核心论据（Key Arguments）

- 按重要性排序的 3-5 个核心论据
- 每个论据包含：
  - 论点标题
  - 支撑数据/证据
  - 逻辑链条

### 3. 风险提示（Risk Factors）

- 可折叠的风险清单
- 每条风险包含：
  - 风险描述
  - 触发条件
  - 影响程度（高/中/低）

### 4. 数据源目录（Source Catalog）

- 引用的所有数据源
- 包含来源类型、时间、可信度

### 5. 后续建议（Follow-up Suggestions）

- 最多 3 个建议的后续问题
- 基于当前分析的自然延伸

## 事实保护规则

### 严格保留

- 股票代码、名称、市场
- 价格、涨跌幅、成交量等数值
- 日期、时间框架
- 技术指标数值（MA、RSI、MACD 等）
- 支撑位、阻力位
- 最终操作建议（买入/持有/卖出）
- 风险提示和免责声明

### 禁止行为

- 不得编造原始回答中不存在的数据
- 不得改变原始结论的方向性
- 不得删除或弱化风险提示
- 不得添加原始回答未提及的标的或策略
- 不得修改价格、日期、数值等硬事实

### 允许操作

- 调整段落顺序（结论先行）
- 合并重复内容
- 拆分长段落为要点列表
- 添加小标题和层级结构
- 优化措辞清晰度（不改变语义）
- 删除冗余过渡句

## 降级策略

- 若 LLM 调用失败或超时（>8秒），返回原始回答
- 若事实校验失败，返回原始回答并记录警告
- 若 `analysis_brief` 缺失，跳过精编，返回原始回答
